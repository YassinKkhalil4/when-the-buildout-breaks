# Site assets

Fonts, favicon and share image used by `dashboard.html` and the paper built by `build_site.py`.
Serve this folder at `/assets/` (see `deploy/Caddyfile.example`).

| File | What | License |
|---|---|---|
| `fonts/geist.woff2`, `fonts/geist-mono.woff2` | Geist and Geist Mono (latin subset) | SIL Open Font License 1.1, Vercel |
| `fonts/source-serif-4-*.woff2` | Source Serif 4, roman and italic (latin subset) | SIL Open Font License 1.1, Adobe |
| `favicon.svg`, `aibust-og.png` | Site icon and social share image | Same as the repository |
